# 7Books

7Books is a modern web application for reading and editing PDF books. Users can upload PDF files, convert them into editable DOCX documents, and enjoy a customizable reading experience with multiple themes.

## Features

- Upload PDF books
- Automatic PDF to DOCX conversion
- Read and edit books
- Multiple reading themes
- Responsive interface
- User authentication
- Personal library management

## Tech Stack

- React
- Vite
- React Router
- JavaScript
- CSS
- Node.js Backend
- MongoDB
